# Roadmap

## Milestone 1: protocol core

- Signed portable build attestations
- Upgrade-aware quorum policy
- Rust and TypeScript SDK compatibility
- Local evaluation CLI

## Milestone 2: evidence worker

- Solana Verify adapter
- pinned build-image digest enforcement
- content-addressed repository checkout
- isolated no-network build execution
- transcript and artifact hashing
- twenty-program reproducibility corpus

## Milestone 3: live Solana data

- finalized upgradeable-loader watcher
- Otter Verify PDA reader
- stale-attestation invalidation
- public read API and webhooks

## Milestone 4: devnet network

- operator registration
- commit and reveal
- quorum finalization
- challenge freezing
- SOL or USDC job payments

## Token launch gates

A transferable token is out of scope until all of these are true:

- five independent operators
- three paying teams
- one wallet or explorer integration
- one thousand completed verification jobs
- audited staking and dispute programs
- ninety stable testnet days
